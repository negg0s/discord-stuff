# Discord Stuff

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Two Vencord userscripts. They are local experiments, not supported products.

## Warning

These scripts automate Discord quests and Steam playtime. That can violate the Discord or Steam terms of service and can get an account limited or banned. Do not run them on an account you care about. Do not use them to farm rewards for other people.

The scripts are published for study and local testing. There is no warranty and no support.

## Scripts

- `scripts/discord-quests-orion.js`: Orion quest helper for Discord.
- `scripts/steam-game-farmer.js`: Steam game farming helper.

## Requirements

- Discord desktop client with Vencord installed.
- Vencord setting "Developer Tools" enabled.
- Browser or Discord console access.

## How to run

1. Open Discord.
2. Press `Ctrl + Shift + I` to open DevTools.
3. Go to the Console tab.
4. Type `allow pasting` and press Enter.
5. Copy the full contents of a script file.
6. Paste it into the console and press Enter.

## Notes

- Scripts run only in your local client.
- Restart Discord to stop a running script.
- The scripts can break when Discord changes its web client.
- Read the code before you run it. It has access to your session.
