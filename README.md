# Discord Stuff

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)


Two browser/Discord userscripts.

## Scripts

- `scripts/discord-quests-orion.js` - Orion quest helper for Discord.
- `scripts/steam-game-farmer.js` - Steam game farming helper.

## Requirements

- Discord desktop client with Vencord installed.
- Vencord setting "Developer Tools" enabled.
- Browser/Discord console access.

## How to run

1. Open Discord.
2. Press `Ctrl + Shift + I` to open DevTools.
3. Go to the Console tab.
4. Type `allow pasting` and press Enter.
5. Copy the full contents of a script file.
6. Paste it into the console and press Enter.

## Notes

- Scripts run only in your local client.
- Restart Discord to stop a running script.
- Use at your own risk. These scripts may violate Discord or Steam terms of service.
